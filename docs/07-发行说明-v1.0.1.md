## 一、这个版本做了什么

一个**跑在相机内部**的机内间隔拍照工具：按设定的间隔连续拍摄静态原图，直接写入相机 SD 卡。
**只输出照片，默认不合成延时视频**；视频合成只是拍摄结束弹窗里的可选附加项，默认选项为“否”。

- 间隔设置：1.0 ~ 3600.0 秒，步进 0.1 秒（最短 1 秒，受机身机械快门与写卡速度限制）
- 张数设置：固定张数 1 ~ 9999 张，或无限连拍直到手动停止
- 存储格式：仅 JPG / 仅 RAW(ARW) / JPG+RAW（实际格式跟随相机机内菜单设置）
- 曝光锁定：拍第一张后锁定对焦与曝光，避免后续画面明暗跳动
- 预览开关：运行中可关闭实时预览以降低发热、提升长时间连拍稳定性
- 运行界面：已拍张数、剩余张数、距下一张倒计时（0.1 秒精度）、状态文字
- 暂停/继续：随时暂停，继续后不重置计数
- 错误保护：SD 卡未插入/已满/读写失败、机身过热 → 立即停止并中文报错
- 按键：仅用相机实体按键（不接收触摸事件），界面 640×480

## 三、安装方法（刷入相机）

1. 电脑端安装 [PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE)：下载官方 release 里的 `pmca-console-v0.18-win.exe` / `pmca-gui-v0.18-win.exe`（**注意：PyPI 上没有 `pmca-re` 包，`pip install pmca-re` 会失败**）
2. 相机 `MENU → 设置 → USB连接` 选择 **MTP**，用 USB 连接电脑（相机保持开机亮屏）
3. 执行：`pmca-console-v0.18-win.exe install -f PMCA_IntervalCapture.apk`
4. 看到 `Task completed successfully` 后，相机 USB 会重启一次；安装完成后**关机再开机**，在 `MENU → 应用程序 → 应用程序列表` 中启动「间隔拍照」

> 若第一次报 `MTP SendCommand failed: 0x-7ff8ff56`（= `0x800700AA` 设备忙）或 `0x-7ff8fe4f`（= `0x800701B1` 设备失效），**不要改 APK**，直接重跑一次 `install -f`，通常第 2 次即可成功。

详细图文流程（含 apk2spk 离线打包方式、卸载回滚、故障排查）见仓库
[docs/02-打包与PMCA-RE刷入教程.md](https://github.com/wangjunhan131/PMCA_IntervalCapture/blob/main/docs/02-打包与PMCA-RE刷入教程.md)。

## 四、已知限制（重要）

- 机身最短稳定间隔约 1 秒；**单张曝光时间会占用拍摄周期**，长曝光（如 0.6 s 以上）时实际间隔必然大于设定值，界面会显示溢出次数，无法保证 100% 严格。
- 图像格式（JPG/RAW/JPG+RAW）最终由相机机内菜单决定，应用侧读取并提示，不强行改写机内设置。
- 机身温度采用每 5 张轮询 `Temperature.getStatus()` 的方式判断（不同固件版本回调方法签名不一致，故不注册回调，避免闪退）。
- 本应用**不调用任何视频录制/编码接口**，机内永不生成视频文件；选择“是”时仅写一份 `PMCACAP/TIMELAPSE_JOB.TXT` 任务清单（照片数/间隔/建议 24fps/ffmpeg 示例），供电脑端后处理。
- A6500 机内**没有**“每隔 N 秒拍一张”的原生功能（索尼把它放在需另外安装的 Timelapse 应用里），所以这个应用解决的是“机内原生做不到”的需求。

## 五、风险警告（请务必阅读）

- ⚠️ 向相机刷入第三方 PMCA 应用存在**固件损坏、相机变砖**风险，一切后果自负。
- ⚠️ 长时间高速连拍会**加速机械快门损耗并导致相机过热**，请控制拍摄时长。
- ⚠️ 曝光时长占用拍摄周期，**无法保证设定间隔 100% 严格生效**。
